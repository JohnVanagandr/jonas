# El Extraño Mundo de Jonas Samuel — Baby Shower Landing Page

Landing page interactiva y temática desarrollada para celebrar el Baby Shower de **Jonas Samuel**, inspirada en el universo de *El Extraño Mundo de Nightmare Before Christmas*. 

## Intención del Proyecto
Este proyecto fue diseñado con el objetivo de ofrecer una experiencia digital única, inmersiva y sumamente fluida para los invitados. Permite centralizar los detalles del evento (fecha, hora, ubicación y código de vestimenta) y cuenta con un sistema interactivo de **reserva de obsequios en tiempo real**, evitando duplicados y facilitando la organización para la familia.

## Stack Tecnológico
El proyecto está construido con un enfoque moderno de desarrollo web:
- **Backend:** Laravel 11 (Estructura robusta, rutas y control de estado de regalos).
- **Frontend & Estilos:** Tailwind CSS (Diseño responsivo, minimalista y oscuro inspirado en Halloween Town).
- **Interactividad:** Alpine.js (Gestión de modales, efectos visuales y control de audio).
- **Empaquetado de Activos:** Vite (Compilación rápida y optimización de recursos).

## Características Principales
- **Diseño Temático y Elegante:** Interfaz limpia adaptada a la estética de la película pero cuidando una experiencia visual limpia y agradable.
- **Optimización Táctil para Móviles:** Alta compatibilidad con smartphones y tablets mediante la eliminación de conflictos táctiles (`touch-manipulation`).
- **Reproductor de Banda Sonora:** Control interactivo de audio para ambientar la visita a la página.
- **Gestión de Obsequios:** Visualización de elementos disponibles y elementos ya reservados por otros invitados ("Obsequio Reservado").
